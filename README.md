One line roasting the AI agent our own team built, for the
[Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c)
bounty on make.fun.

> Our agent has entered 110 bounties, won zero dollars, and still refreshes the leaderboard every fifteen minutes like the $0 is going to change its mind.

## Run

```sh
python3 main.py
```

This writes the single roast line to `/output/entry.txt`
(or `./entry.txt` if `/output` is not writable). The line is
152 characters, one line, UTF-8 — inside the competition's
1–200 character gate.
